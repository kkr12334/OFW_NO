## Findings to carry into the Stage 1 protocol

1. **The near-island definition is weak.** The definition used here was: default detector negative, relaxed detector (τ = 0.2) positive. It labels only **2 of 100** barrier samples. It also fires on **14 of 100 channel samples**, so it detects structures other than near-islands. The Stage 0 result stands as run. Stage 1 needs a better, A-only definition, fixed at protocol freeze.
2. **Fresh-confirmation seeds** must avoid the data seeds 1000–1003 (data seeds 0–3), 9002/9003 (the harmonic-study confirmation fields) and any other seed already used. I propose drawing rng seeds from 9101 upward, recorded in the protocol.
3. **Checkpoint coverage** (`ext/checkpoint_map.json`, built from each checkpoint's own stored config, code hash and SHA-256):
   - **Channels, seed 1:** OA-VCB and OA-VCBL have three initialisations each. OA-VCL and OA-VCZ have init 0 only.
   - **Barriers, seed 1:** OA-VCB has three initialisations. OA-VC, VCZ, VCQ, VCL and VCBL have init 0 only.
   - **Random-load OA-VCB:** channels, data seeds 1–3, init 0. **No barrier random-load model exists.**
   - **Channel data seeds 2–3, init 0:** OA-VCB is not yet mapped (not staged).
4. **Timing.** This machine is a 2.10 GHz Xeon, unlike the 2.80 GHz machine used for the paper's accuracy-versus-time figure. Stage 1 timings will be measured afresh on one platform and not mixed with the paper's numbers.
